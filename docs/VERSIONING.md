# kilons version policy

Current version: **0.2.1**. Version numbering was reset for the new policy; the source history and implemented features remain intact.

- Format: `X.Y.Z`.
- `X`: major version, currently 0.
- `Y`: new feature/release cycle; increment and reset Z to 0.
- `Z`: fixes and security patches only; no new features.
- When a cycle ends, archive the full source as a ZIP snapshot. Do not extend closed release cycles.
- Historical Milestone/M-number names are legacy development labels, not release versions.
- Example: `0.1.0` -> `0.1.1` for a fix, or `0.2.1` for a new feature cycle.
